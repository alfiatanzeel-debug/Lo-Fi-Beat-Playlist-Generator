# 🎧 Lo-Fi Beat Playlist Generator (AI Workshop Edition)

A modern, responsive, aesthetic web application built for the AI Workshop that curates personalized lo-fi playlists based on mood, tempo, and atmospheric vibes. Powered by **Google Gemini AI**, **Next.js 14**, **Tailwind CSS**, and **Supabase**.

---

## ✨ Features

- 📊 **Dynamic Dashboard:** Real-time metrics on total collections, tracks, listening hours, and mood distribution breakdowns.
- 🤖 **Google Gemini AI Playlist Generator:** Curates playlist names, descriptions, and authentic tracks with realistic BPMs, durations, and musical keys tailored to moods (*Study*, *Focus*, *Relax*, *Sleep*, *Rainy Day*, *Chill*, *Coffee Shop*, *Late Night*).
- 💿 **Interactive Music Player:** Persistent bottom player featuring an animated vinyl turntable, track progress scrubber, volume controls, and realistic **Web Audio API procedural lo-fi synthesizer** (so you can hear warm Rhodes chords and soothing noise without external CDNs).
- 🌧️ **Atmosphere Studio & Pomodoro Timer:** Mix real-time background soundscapes (gentle window rain, vinyl needle crackle, cozy cafe murmur) paired with a 25/45/60-minute deep work timer.
- 🗄️ **Supabase Cloud + Demo Mode Fallback:** Connects seamlessly with Supabase PostgreSQL or runs 100% offline using client-side persistent storage when credentials are not yet supplied.
- 🔍 **Search, Filter & Manage:** Search by song title, artist, or vibe tags. Filter by mood category or favorites. Edit playlist details or add/remove tracks.
- 📥 **Export & Backup:** One-click downloads of playlists as formatted **CSV** or indented **JSON**, plus full multi-playlist backup and restore.
- 🎨 **Lo-Fi Aesthetic:** Dark purple/pink/cyan neon gradients, vinyl sleeve slide-out animations, glassmorphism panels, and retro lo-fi typography.
